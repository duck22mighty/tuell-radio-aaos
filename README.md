# Tuell Radio AAOS

Custom Android Automotive / ARM64 GSI project for the Tuell Radio head unit.

Target hardware:
- onn 7" Core Tablet (2026)
- MediaTek MT8786
- ARM64
- Android 16 vendor
- Treble / dynamic partitions

Target Android configuration:
- Android Automotive OS
- A2DP Sink
- AVRCP Controller
- HFP Client
- PBAP Client
- MAP Client
- Tuell Radio system application
